## 3. Ekrany

**Dashboard**: 4 kafle statystyk (w tym mies.: liczba wycen, wartość wysłanych, akceptacja %, średnia wartość); lista „Ostatnie wyceny" (5); karta „Subskrypcja" z paskiem postępu triala/okresu (nawiązanie do „Account Progress" z inspiracji).

**Wyceny (lista)**: tabela-karta: numer, klient, tytuł, status (pill), suma, zaktualizowano, menu `⋯` (Duplikuj / PDF / Archiwizuj). Filtry jako pills nad tabelą. Pusty stan z CTA.

**Edytor wyceny** (najważniejszy ekran):
```
┌ Topbar: ← Wyceny | WYC/2026/08/0012 (edytowalne) | status pill | [Podgląd/Edycja] [PDF ▾] [⋯] ┐
├ lewa kolumna (flex-1) ───────────────────────┬ prawa kolumna (340px, sticky) ┤
│ Karta: Nagłówek (tytuł, klient, daty, wstęp)  │ Karta: Podsumowanie           │
│ Karta per Sekcja:                             │   Suma pozycji                │
│   tytuł sekcji (inline edit)                  │   Rabaty (terakota)           │
│   Grupa ▾ (inline edit, drag)                 │   ── Razem netto (duże)       │
│     ItemRow: [drag] [toggle] nazwa/opis  cena │   VAT / brutto                │
│     + Pozycja  + Z biblioteki                 │   Ważna do: …                 │
│   + Grupa                                     │ Karta: Klient (skrót)         │
│ + Sekcja                                      │ Karta: Notatki wewn. (f2)     │
└───────────────────────────────────────────────┴───────────────────────────────┘
```
- `ItemRow`: toggle (czarny gdy on), nazwa bold, opis szary, cena tabular, w trybie edycji: input ceny, qty, handle, usuń, „zapisz do biblioteki" (ikona zakładki; po zapisie ptaszek).
- Podgląd = ten sam komponent bez kontrolek (jak `.edit-mode` w prototypie), **nie** osobny widok.
- Wskaźnik autosave przy numerze: „Zapisano 12:04" / „Zapisywanie…" / „Błąd — ponów".
- `LibraryPicker`: popover z wyszukiwarką, grupowanie po kategorii, Enter wstawia. Dla grup — osobna zakładka.

**Biblioteka**: dwie zakładki (Pozycje / Grupy), grid kart z kategorią, inline edit, akcje masowe, import CSV (f2). Dialog „Zastosować zmiany w otwartej wycenie?" przy edycji pozycji (kaskada z prototypu).

**Szablony**: grid kart: nazwa, data, liczba pozycji, suma; „Nowa wycena z szablonu", „Nadpisz bieżącą", usuń.

**Branding**: 2 kolumny — formularz | live preview PDF.

**Subskrypcja**: status, plan, data, przyciski; historia faktur — link do Portalu.

**Auth**: 1 karta na środku, bez sidebara. Login / Rejestracja (nazwa firmy + e-mail + hasło) / Reset / Google.

## 5. Interakcje
- Drag & drop: `@dnd-kit/core` + `sortable`, tylko w trybie edycji, sensory: pointer + keyboard.
- Inline edit: `contentEditable` **nie** — używamy kontrolowanych `<input>` stylizowanych na tekst (prostsze z React, bez problemów z kursorem). Enter = zapisz, Esc = cofnij.
- Kwoty: input przyjmuje „1 200", „1200,50", „1200.5" → `parseMoney()`; blur formatuje.
- Animacje: `framer-motion` tylko do `layout` przy reorder i wejść list. Bez przesady.
- Skróty: `⌘/Ctrl+S` wymusza zapis, `⌘/Ctrl+P` PDF, `⌘/Ctrl+K` paleta (f2).
